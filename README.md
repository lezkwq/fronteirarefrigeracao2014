# Fronteira Refrigeração

Demo institucional em TanStack Start. Use Node.js 22.12 ou superior.

- `npm ci` instala as dependências.
- `npm run dev` abre o servidor local.
- `npm test` verifica o roteamento.
- `npm run build` compila o projeto.

A Vercel detecta o framework pelo arquivo `vercel.json`. O Nitro seleciona o
alvo de hospedagem conforme o ambiente de build.
